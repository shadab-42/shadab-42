### 🔐 2. DynaShare – Dynamic File Sharing

<p align="center">
  <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python" />
  <img src="https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white" alt="Flask" />
  <img src="https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white" alt="SQLite" />
  <img src="https://img.shields.io/badge/File%20Encryption-Fernet-blue?style=flat-square" alt="Encryption" />
</p>

A Flask-based secure file-sharing web application designed to provide encrypted file storage and controlled file access.

**Key Features**

- User registration and authentication.
- File encryption using Fernet symmetric encryption.
- UUID-based unique file names and sharing links.
- Configurable sharing-link expiration.
- Manual link revocation.
- Database management using SQLAlchemy and SQLite.

**Technologies:** Python, Flask, SQLAlchemy, SQLite, HTML, CSS, Bootstrap, Werkzeug and Cryptography.
